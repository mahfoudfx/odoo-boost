## Odoo 16 Specific Notes & API Highlights

### Key Architecture Changes
- **OWL 2.x Standardized**: Full web client rewritten on OWL 2.x.
  - Services registered via `registry.category("services").add("my_service", myService)`.
  - Views defined as OWL components (`registry.category("views").add(...)`).
- **Command Object Recommended**: `from odoo import Command` is the officially recommended approach for relational field writes.
- **ORM Performance**: Substantial improvements to ORM caching and batch operations.
- **QWeb Views**: Still supports `attrs`, but inline expressions start being prepared.
