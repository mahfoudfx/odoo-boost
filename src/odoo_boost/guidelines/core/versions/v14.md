## Odoo 14 Specific Notes & API Highlights

### Key Architecture Patterns
- **Legacy Web Client**: Uses legacy widgets (`web.Widget`) alongside early Owl components; inspect the component being extended.
- **Assets Registration**: Assets are declared via XML records (`<template id="assets_backend" inherit_id="web.assets_backend">`), NOT in `__manifest__.py`.
- **Relational Field Writes**: Legacy tuple syntax is standard:
  ```python
  record.write(
      {
          "line_ids": [
              (0, 0, {"name": "New line"}),
              (1, line_id, {"qty": 5}),
              (2, line_id, 0),  # Delete
              (6, 0, [id1, id2]),  # Replace
          ]
      }
  )
  ```
- **Name Display**: Use `name_get()` and `name_search()` to format display names.
- **View Attributes**: `attrs` dictionary syntax is standard for dynamic UI:
  ```xml
  <field name="partner_id" attrs="{'invisible': [('state', '=', 'draft')], 'required': [('state', '=', 'confirmed')]}"/>
  ```
