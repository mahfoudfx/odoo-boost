## Odoo 17 Specific Notes & API Highlights

### Key Changes in Odoo 17
- **`name_get()` Deprecated**: Replaced by `_compute_display_name()`.
  ```python
  # Odoo 17+ pattern
  @api.depends("name", "reference")
  def _compute_display_name(self):
      for record in self:
          record.display_name = (
              f"[{record.reference}] {record.name}" if record.reference else record.name
          )
  ```
- **New list view tag**: Use `<list>` instead of `<tree>` (both still work but `<list>` is preferred).
- **Upgraded OWL 2**: OWL 2 is the standard. Components use `setup()` instead of `constructor()`.
- **Form view attrs removal**: `attrs` attribute is deprecated. Use `invisible`, `readonly`, `required` directly as Python expressions:
  ```xml
  <!-- Old (pre-17) -->
  <field name="x" attrs="{'invisible': [('state', '=', 'draft')]}"/>
  <!-- New (17+) -->
  <field name="x" invisible="state == 'draft'"/>
  ```
- **Markup utility**: Use `Markup` from `markupsafe` for safe HTML in Python.

### Deprecated / Removed in v17
- `name_get()` is deprecated — use `_compute_display_name()`.
- `attrs` dict syntax on view elements is deprecated in favor of inline expressions.
- `<tree>` tag still works but `<list>` is preferred in new code.
- `@api.multi` was removed in v13 — do not use it.

### Recommended Patterns
- Use the new expression syntax for view conditions: `invisible="not is_company"`.
- Use `env.ref()` instead of low-level `ir.model.data` lookups.
- Use `Command` constants for relational writes:
  ```python
  from odoo import Command

  record.write(
      {
          "line_ids": [
              Command.create({"name": "New line"}),
              Command.update(line_id, {"qty": 5}),
              Command.delete(line_id),
          ]
      }
  )
  ```
