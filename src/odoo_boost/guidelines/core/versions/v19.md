## Odoo 19 Specific Notes

### Key Changes in Odoo 19
- Check each inherited pattern against Odoo 19; changed APIs are listed below.
- **Python runtime**: Odoo documents Python 3.10+; follow the deployment and project tooling requirements.
- **`<tree>` is removed**: Only `<list>` is supported for list views.
- **Improved typing**: Better type hints in Odoo's own codebase.
- **Enhanced OWL**: Continued improvements to the OWL framework and developer experience.
- **Performance focus**: Various ORM and query optimizations.

### Search Views — Breaking Changes
- **`expand` attribute removed**: The `expand` attribute on `<group>` inside search views is no longer valid and will fail RNG validation.
- **`string` attribute on `<group>` removed**: The `string` attribute on `<group>` inside search views is no longer valid.
- Replace `<group expand="0" string="Group By">` with just `<group>`.
- The `string` attribute on the `<search>` root element is still tolerated but remains inert (not displayed).

### Recommended v19 Patterns
- Use `<list>` exclusively — `<tree>` will cause errors.
- Inline expressions for view conditions are the only option (no `attrs`).
- Use only Python syntax supported by the project runtime.
- Use modern `Command` API for all relational field operations.
- Flush relevant pending fields before SQL reads; select the narrowest supported
  flush API. SQL writes also require cache invalidation and dependency notification.

### Migration Notes (from v18 to v19)
- Replace any remaining `<tree>` tags with `<list>`.
- Remove `expand` and `string` attributes from `<group>` elements in search views.
- Verify all view expressions use the inline syntax.
- Check for deprecated API usage flagged in v18 that's removed in v19.
- Test with the deployment Python version and verify third-party dependencies.

### Controller Route Change
- JSON-RPC controllers use `type="jsonrpc"` instead of `type="json"`.


### Audited compatibility boundaries
- `json` remains a deprecated alias; new JSON-RPC code uses `jsonrpc`.
- `fields.Domain` and `models.Constraint` are documented here, not only in 20.
- Cron batching uses `_commit_progress`. Unit-of-measure and fiscal-position
  configuration differ from 18; consult the respective domain skill tables.
- Access declarations still use `ir.model.access` plus `ir.rule`; the audited
  unified `ir.access` model belongs to 20.

Official baseline: [Odoo 19 developer reference](https://github.com/odoo/documentation/tree/19.0/content/developer).
The version-audit reports record precise per-claim evidence and limits.
