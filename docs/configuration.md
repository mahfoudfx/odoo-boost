# Configuration Reference

Odoo Boost stores project configuration in `odoo-boost.json` at your project root. This file is generated by `odoo-boost install` and read by all other commands.

## odoo-boost.json Schema

```json
{
  "connection": {
    "url": "http://localhost:8069",
    "database": "mydb",
    "username": "admin",
    "password": "admin",
    "protocol": "xmlrpc"
  },
  "odoo_version": "18.0",
  "agents": ["antigravity", "claude_code", "cursor"],
  "project_path": "."
}
```

### `connection` (required)

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `url` | string | yes | — | Odoo server URL, e.g. `http://localhost:8069` |
| `database` | string | yes | — | Database name |
| `username` | string | no | `"admin"` | User login or email |
| `password` | string | no | `"admin"` | User password or API key |
| `protocol` | string | no | `"xmlrpc"` | Connection protocol (`"xmlrpc"`) |

### `odoo_version` (optional)

Detected Odoo version string (e.g. `"14.0"`, `"15.0"`, `"16.0"`, `"17.0"`, `"18.0"`, `"19.0"`). Auto-detected during `odoo-boost install`.

### `agents` (optional)

List of enabled agent identifiers. Valid options:

- `"antigravity"` — Antigravity (App & CLI `agy`)
- `"claude_code"` — Claude Code
- `"cursor"` — Cursor
- `"copilot"` — GitHub Copilot
- `"codex"` — OpenAI Codex
- `"opencode"` — OpenCode
- `"pi"` — Pi
- `"hermes"` — Hermes
- `"windsurf"` — Windsurf
- `"cline"` — Cline
- `"junie"` — Junie

Default: `[]` (all configured agents).

### `project_path` (optional)

Path to the project root directory. Default: `"."`.

## CLI Commands Reference

### `odoo-boost install`
Interactive setup wizard. Discovers connection details, checks versions and tools, and installs agent guidelines and skills.

### `odoo-boost check`
Verifies live connection and prints server diagnostics.

| Option | Description |
|---|---|
| `--url` | Odoo server URL (overrides config) |
| `--database` | Database name (overrides config) |
| `--username` | Username (overrides config) |
| `--password` | Password or API key (overrides config) |
| `--config`, `-c` | Explicit path to `odoo-boost.json` |

### `odoo-boost lint [path]`
Runs static checks on local addons or files using `pylint-odoo` (if installed) or the built-in AST safety scanner (checking for missing ACLs, SQL injections, commit violations, and deprecated tags).

| Option | Description |
|---|---|
| `path` | Path to module or file (defaults to `.`) |

### `odoo-boost update`
Regenerates guidelines, MCP configs, and skill files from the saved `odoo-boost.json`.

| Option | Description |
|---|---|
| `--config`, `-c` | Explicit path to `odoo-boost.json` |

### `odoo-boost mcp`
Starts the stdio MCP server for agent communication.

| Option | Description |
|---|---|
| `--config`, `-c` | Explicit path to `odoo-boost.json` |

## Security Best Practices

`odoo-boost.json` contains connection credentials. Always:
- Ensure `odoo-boost.json` is added to `.gitignore`.
- Prefer Odoo API Keys over passwords whenever possible.
- Use a dedicated Odoo technical user with appropriate access permissions.
